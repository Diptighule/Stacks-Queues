Unit IV – Stacks and Queues
Aim
To implement Stack and Queue data structures using arrays and linked lists in C++, and maintain the source code using Git and GitHub.

Description
This repository contains four C++ programs developed as part of the Unit IV – Stacks and Queues academic activity. It demonstrates basic operations on stacks and queues using two different implementation techniques: arrays and linked lists.

Programs Included
1. Queue Using Array
File: queue_array.cpp

Implements a queue using an array.

Operations:

Enqueue – Insert an element into the queue.
Dequeue – Remove an element from the queue.
Display – Display all queue elements.
Peek – Display the front element.
Handles queue overflow and underflow conditions.
2. Queue Using Linked List
File: queue_linked_list.cpp

Implements a queue using a linked list.

Operations:

Enqueue – Insert a new node at the rear.
Dequeue – Remove a node from the front.
Display – Display all queue elements.
Peek – Display the front element.
Handles empty-queue conditions.
3. Stack Using Array
File: stack_array.cpp

Implements a stack using an array.

Operations:

Push – Insert an element into the stack.
Pop – Remove the top element.
Display – Display the stack elements.
Peek – Display the top element.
Handles stack overflow and underflow conditions.
4. Stack Using Linked List
File: stack_linked_list.cpp

Implements a stack using a linked list.

Operations:

Push – Insert a new node at the top.
Pop – Remove the top node.
Display – Display all stack elements.
Peek – Display the top element.
Handles empty-stack conditions.
Concepts Used
Stack: Follows LIFO (Last In, First Out).
Queue: Follows FIFO (First In, First Out).
Array: Stores elements in a fixed-size sequence of memory locations.
Linked List: Stores elements in dynamically allocated nodes connected by pointers.
